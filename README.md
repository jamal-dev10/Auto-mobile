# Auto-Mobile Parking App (React + Vite)

A modern, responsive React and TypeScript web application for the Auto-Mobile parking platform, rewritten from the original static web template.

## Features Preserved & Enhanced

- **Dynamic Sticky Navigation**: Responsive header that adapts background and branding on scroll, with smooth anchor linking and mobile menu support.
- **Hero & App Showcase**: High-impact banner with gradient overlays, phone mockups, live system status metrics, and direct store links.
- **Core Value Highlights (About)**: 24/7 Support, Cross-Platform compatibility, and Fast reservation feature cards with animated hover interactions.
- **Video Demonstration Modal**: Interactive "Watch Now" showcase featuring embedded video player modal with smooth overlay transitions.
- **Detailed Features Grid**: 3D-tilt feature cards for Find Nearby Parking, Real-time Availability, Secure Payment, Safety Features, Mobile Notifications, and Parking History.
- **Interactive Parking Finder & Reservation Demo**: Interactive live spot locator in Casablanca with occupancy indicators, duration selectors, bay allocation, and instant parking pass generation.
- **Dedicated Driver Portal Page (`/pages/AuthPage.tsx`)**: Standalone, dedicated page route (`#auth`) featuring Sign In and Driver Account Registration, 2-column layout with platform perks, password visibility toggles, one-click demo logins, vehicle plate registration, loyalty parking rewards, and logged-in dashboard.
- **Team Showcase**: Executive profiles with avatar zoom effects and social links (Nitu Singh, Yogesh Singh, Nisha Sharma).
- **Contact & Driver Support**: Validated contact form with submission states and Casablanca headquarters contact information.
- **Store Downloads**: Direct App Store and Google Play badges for iOS and Android.

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler / Server**: Vite
- **Styling**: Poppins typography, FontAwesome 5 icons, tailored CSS with modern gradients and neumorphic touches.

## Development

```bash
# Run development server on port 3000
npm run dev

# Build production bundle
npm run build
```
